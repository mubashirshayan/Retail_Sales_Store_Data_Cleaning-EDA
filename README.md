# 🛒 Retail Store Sales Data Cleaning & Exploratory Data Analysis

## 📌 Project Overview

This project focuses on **data cleaning, preprocessing, and exploratory data analysis (EDA)** of a retail store sales dataset. The objective is to transform raw sales data into a clean, analysis-ready dataset and uncover valuable business insights through visualization and statistical analysis.

The project demonstrates practical data analytics skills including:

* Data Cleaning
* Missing Value Handling
* Data Transformation
* Exploratory Data Analysis (EDA)
* Data Visualization
* Business Insight Generation

---

## 📂 Dataset Information

### Original Dataset

* File: `retail_store_sales.csv`
* Contains raw retail transaction records with inconsistencies and data quality issues.

### Cleaned Dataset

* File: `Clean_retail_store.csv`
* Total Records: **12,575**
* Total Features: **13**

### Features

| Column           | Description                              |
| ---------------- | ---------------------------------------- |
| Transaction ID   | Unique transaction identifier            |
| Customer ID      | Unique customer identifier               |
| Category         | Product category                         |
| Item             | Product name                             |
| Price Per Unit   | Price of each item                       |
| Quantity         | Number of items purchased                |
| Total Spent      | Total transaction amount                 |
| Payment Method   | Payment type used                        |
| Location         | Store location                           |
| Transaction Date | Date of transaction                      |
| Discount Applied | Indicates whether a discount was applied |
| Year             | Transaction year                         |
| Month            | Transaction month                        |
